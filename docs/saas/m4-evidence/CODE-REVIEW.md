## 复用的基础安全边界

入口仍是 Host→活跃租户→已验签 JWT/Session→当前 Owner/客户→不透明内部
上下文。五张新增业务表使用真实事务的 `SET LOCAL` 和受限连接池角色；
无上下文看不到凭据。账户和回调全局目录只提供服务器路由数据，不公开接口。
复合 tenant FK 和唯一键不能被全局共享目录替代。

所有新增订单动作使用有限 method/path/schema 和 Owner 认证。订单项不能仅
依赖商品属于本店，还要属于该订单；发货单要属于该订单，发货项属于该单。
客户端退款 metadata 关闭，恢复标记只能由服务器设置。原生 refund workflow
的可选 metadata 分支没有改变未提供标记的常规退款行为；SaaS 关闭的支付、
订单和取消/credit-line 原生套件单独验证。

API 的操作指纹和 vendor 幂等身份均按租户隔离。浏览器写入仍验证同源 Origin，
回调例外只接受渠道 raw 签名并重新建授权。M2 持久任务执行时重新查租户/身份，
保持至少一次交付；并未降低成员失效检查或把租约续期当作权限续期。
