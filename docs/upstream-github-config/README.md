# Upstream GitHub configuration references

These files are preserved from the MIT Medusa 2.18.0 source snapshot.
They are reference material for future adaptation to Store SaaS.

Medusa's original automation includes releases, scheduled operations, external
notifications and integrations with its own infrastructure. The delivered SaaS
branch keeps those configurations outside `.github/workflows` and retains
Dependabot/CODEOWNERS here when present. No Store SaaS CI or automatic deployment
is registered by this delivery. Verified local commands and results are in the
root README and `docs/saas/m3-evidence/`.
